SentinelOne Integration

Endpoint Detection and Response (EDR) platform for comprehensive endpoint security

About SentinelOne

SentinelOne is an advanced endpoint protection platform that provides real-time threat detection, response, and remediation capabilities. The IRIS integration allows security teams to automate common incident response tasks directly from their investigation workflow.

Configuration Requirements
  • Management Console URL: Your SentinelOne management console base URL
  • API Token: Valid API token with appropriate permissions
  • Required Permissions: Agents read/write, Actions execute, Activities read
Available SOAR Playbooks

containment requires approval

Velociraptor Integration

Advanced digital forensics and incident response platform for deep endpoint analysis

About Velociraptor

Velociraptor is a powerful digital forensics and incident response (DFIR) platform that provides advanced endpoint visibility and artifact collection capabilities. It excels at gathering detailed forensic data from Windows, Linux, and macOS endpoints using a powerful query language and artifact collection framework.

Configuration Requirements
  • Velociraptor Server URL: Your Velociraptor management server URL
  • API Key: Valid API key with appropriate permissions
  • Required Permissions: Client search, Flow creation, Artifact collection
Available SOAR Playbooks
Forensic Collection

Comprehensive forensic artifact collection from target endpoint using Velociraptor's extensive artifact library.

forensics artifacts
Template ID:
velociraptor-collect
What it does:
  1. Locates target client by hostname or client ID in Velociraptor
  2. Initiates collection flow for multiple forensic artifacts:
    • Windows.System.ProcessInfo: Running processes and their details
    • Windows.Network.Netstat: Network connections and listening ports
    • Windows.Registry.RecentDocs: Recently accessed documents from registry
  3. Returns flow ID for monitoring collection progress
  4. Estimates completion time based on artifact complexity
Use Cases: Incident response triage, malware analysis, forensic investigation, threat hunting
Advanced Capabilities

Velociraptor offers extensive artifact collection capabilities beyond the standard playbook:

  • Memory Analysis: Memory dumps and live memory artifact collection
  • File System: MFT parsing, file carving, and timeline generation
  • Registry Analysis: Comprehensive Windows registry artifact extraction
  • Browser Forensics: History, downloads, and cached data from major browsers
  • Event Logs: Windows Event Log parsing and analysis
  • Custom Artifacts: User-defined VQL queries for specific investigation needs

ConnectWise CRM Integration

Professional Services Automation and CRM platform for ticket management

About ConnectWise CRM

ConnectWise is a comprehensive Professional Services Automation (PSA) and Customer Relationship Management (CRM) platform designed for Managed Service Providers (MSPs) and IT service companies. The IRIS integration enables automated ticket creation to streamline incident response workflows.

Configuration Requirements
  • Server URL: Your ConnectWise server URL (cloud or on-premise)
  • Company ID: Your ConnectWise company identifier
  • API Keys: Public and private key pair from API member
  • Client ID: Unique application identifier
  • Default Board: Target board name for ticket creation
  • Required Permissions: Service Desk > Service Tickets - Edit and Inquire Level: All
API Member Setup

Before configuring the integration, you must create an API member in ConnectWise:

  1. Log into ConnectWise Manage → System → Members → API Members
  2. Create a new API member with appropriate security role
  3. Generate API key pair (public/private keys)
  4. Save both keys securely - private key is only shown once!
Cloud vs On-Premise
Cloud Instances

Server URLs:

  • https://api-na.myconnectwise.net (North America)
  • https://api-eu.myconnectwise.net (Europe)
  • https://api-au.myconnectwise.net (Australia)
On-Premise

Server URL Format:

https://your-server.domain.com

Use your organization's ConnectWise server URL

Cisco Meraki Dashboard API Integration

IRIS integrates with Cisco Meraki Dashboard API to provide network control and IP blocking capabilities across your managed infrastructure.

Integration Overview

This integration enables IRIS to automatically block malicious IPs and isolate compromised clients through Meraki firewall rules and client policies. Perfect for network-level containment and threat response.

Available SOAR Playbooks

Block IP Address
Purpose

Block outbound or inbound communication with a malicious IP from Meraki firewall across all networks in your organization.

Workflow
  1. Analyst selects "Block IP on Meraki" from SOAR tab
  2. IRIS retrieves all networks with MX appliances in the organization
  3. Creates firewall rule: DENY any → {malicious_ip} any
  4. Applies rule to all appliance networks with highest priority
  5. Saves enforcement details to artifacts
Artifact Storage

/cases/{case_id}/artifacts/meraki/block_{ip}_{timestamp}.json

API Endpoint
PUT /networks/{networkId}/appliance/firewall/l3FirewallRules
Tags
Containment Requires Approval
Duration

~30-60 seconds per network

Block Client
Purpose

Isolate a specific host by MAC or IP using Meraki client policy to prevent network access.

Workflow
  1. Analyst provides IP address or MAC address of target client
  2. IRIS searches all networks for the specified client
  3. Sets client policy to "Blocked" to prevent network access
  4. Logs client details including switch and network information
  5. Saves blocking confirmation to artifacts
Artifact Storage

/cases/{case_id}/artifacts/meraki/block_client_{target}_{timestamp}.json

API Endpoint
PUT /networks/{networkId}/clients/{clientId}/policy
Tags
Isolation Requires Approval
Duration

~15-30 seconds

Verify Network Event
Purpose

Confirm enforcement by fetching Meraki event logs to verify blocking has taken effect.

Workflow
  1. Analyst requests verification for a specific IP address
  2. IRIS queries event logs from all appliance networks
  3. Filters events for the target IP in firewall logs
  4. Collects blocking confirmations and denied connection attempts
  5. Stores proof of enforcement as JSON artifacts
Artifact Storage

/cases/{case_id}/artifacts/meraki/verify_{ip}_{timestamp}.json

API Endpoint
GET /networks/{networkId}/events
Tags
Verification Forensics
Duration

~10-20 seconds

Setup Requirements
  • Dashboard API Access: Enable API access in Organization → Settings → Dashboard API access
  • API Key: Generate API key with full organization access
  • Organization ID: Obtain from Dashboard URL or API call to /organizations
  • MX Appliances: At least one MX device required for firewall rule management
  • Network Topology: Ensure proper VLAN and firewall rule hierarchy
Network Architecture Notes
  • Firewall rules are applied at the network level (per MX appliance)
  • New rules are inserted at the top for highest priority enforcement
  • Client blocking uses device policy for immediate network isolation
  • Event logs provide verification of rule enforcement effectiveness
  • Rate limiting applies - respect API throttling responses

HaveIBeenPwned

Credential exposure intelligence and breach data lookup service

About HaveIBeenPwned

HaveIBeenPwned (HIBP) provides API endpoints to check if an email address, domain, or password hash appears in known breach datasets. This adds user compromise context to IRIS cases — ideal for business email compromise or account investigation.

Configuration Requirements
  • API Key: Valid HIBP API key (obtain from haveibeenpwned.com)
  • API Base URL: https://haveibeenpwned.com/api/v3 (default)
  • Rate Limiting: Minimum 1.5 seconds between API calls
  • Required Permissions: Search breached accounts and domain breaches
Available SOAR Playbooks
Email Exposure Check

Determine if an email address in a case appears in any data breaches.

forensics credential-intelligence
Template ID:
hibp-email-check
What it does:
  1. Calls GET /breachedaccount/{email} with HIBP API key
  2. Parses breach data and counts exposures
  3. Stores JSON output as case artifact
  4. Adds case note with breach summary
Use Cases: Business email compromise investigation, user account security assessment
Domain Exposure Check

Identify if any company-owned domains have appeared in breaches.

forensics credential-intelligence
Template ID:
hibp-domain-check
What it does:
  1. Calls GET /breaches?domain={domain} with HIBP API key
  2. Retrieves all breaches affecting the domain
  3. Creates breach summary table with dates and counts
  4. Logs results as Markdown table in case note
Use Cases: Organization security assessment, domain risk evaluation
Password Reuse Check

Verify if a password hash appears in known compromised password datasets using k-anonymity.

forensics password-security
Template ID:
hibp-password-check
What it does:
  1. Hashes password using SHA-1 (if not already hashed)
  2. Uses k-anonymity: sends only first 5 chars to API
  3. Calls GET /range/{prefix} to get candidate hashes
  4. Locally matches full hash to avoid password disclosure
Use Cases: Password security assessment, credential compromise analysis
Security: Full password never transmitted to API
API Rate Limiting

HIBP enforces rate limiting. The integration includes a configurable delay (default: 1.6 seconds) between API calls to respect these limits. Adjust the rate limit delay in integration settings if needed.

File Storage Convention

All HIBP results are stored in case artifacts following the pattern:

  • /cases/{case_id}/artifacts/hibp/hibp_email_{email}_{job_id}.json
  • /cases/{case_id}/artifacts/hibp/hibp_domain_{domain}_{job_id}.json
  • /cases/{case_id}/artifacts/hibp/hibp_password_check_{job_id}.json

FortiGate Firewall Integration

Enterprise firewall and network security platform for automated threat containment

About FortiGate

FortiGate is Fortinet's flagship enterprise firewall platform that provides comprehensive network security, including advanced threat protection, VPN capabilities, and network segmentation. The IRIS integration enables automated blocking of malicious IPs, domains, and quarantine actions through the FortiGate REST API.

Configuration Requirements
  • API Key: Valid FortiGate API key with appropriate permissions
  • Base URL: Your FortiGate management interface URL (e.g., https://fortigate.company.com)
  • API Version: Supported versions v1 or v2 (recommended: v2)
  • VDOM: Virtual Domain name (use 'root' for single VDOM setups)
  • Quarantine Duration: Default duration in hours for user/IP banning (default: 24)
  • Required Permissions: Firewall policy management, address object creation, web filter management
API Key Setup

Create an API key in FortiGate with appropriate permissions:

  1. Log into FortiGate → System → Administrators → Create New → REST API Admin
  2. Set Administrator Profile with required permissions (Super Admin or custom profile)
  3. Configure trusted hosts if needed for additional security
  4. Generate and save the API key securely - it's shown only once!
Available SOAR Playbooks
Block Malicious IP Address

Create firewall address object and deny policy to block communication with malicious IP addresses.

containment requires-approval
Template ID:
fortigate-block-ip
What it does:
  1. Creates a firewall address object for the malicious IP
  2. Creates a deny firewall policy targeting the IP address
  3. Places the policy at high priority for immediate enforcement
  4. Stores policy creation details as case artifact
API Endpoints: POST /api/v2/cmdb/firewall/address/, POST /api/v2/cmdb/firewall/policy/
Use Cases: IOC blocking, malware C2 prevention, threat actor IP containment

  1. Creates a web filter URL filter for the malicious domain

API Endpoint: POST /api/v2/cmdb/webfilter/urlfilter/
Use Cases: Phishing domain blocking, malware hosting sites, suspicious URL containment
Quarantine Host (Ban User/IP)

Temporarily ban users or IP addresses from network access for specified duration.

containment temporary

fortigate-quarantine-host
What it does:
  1. Adds user or IP address to FortiGate's banned user list

API Endpoints: POST /api/v2/monitor/user/banned/add, GET /api/v2/monitor/user/banned/list
Use Cases: Compromised host isolation, suspicious user containment, incident response quarantine
VDOM Support

FortiGate supports Virtual Domains (VDOMs) for multi-tenancy. Specify the correct VDOM name in the integration configuration. Use 'root' for single VDOM deployments or the specific VDOM name for multi-VDOM environments.

File Storage Convention

All FortiGate SOAR results are stored in case artifacts following the pattern:

  • /cases/{case_id}/artifacts/fortigate/block_ip_{ip}_{job_id}.json
  • /cases/{case_id}/artifacts/fortigate/block_domain_{domain}_{job_id}.json
  • /cases/{case_id}/artifacts/fortigate/quarantine_{target}_{job_id}.json

  • VDOM Management: Full support for single and multi-VDOM environments
